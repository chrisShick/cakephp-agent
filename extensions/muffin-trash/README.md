# muffin-trash

Capability pack for **[`muffin/trash`](https://github.com/usemuffin/trash)** (`UseMuffin/Trash`) soft-deletes on CakePHP 5.

Detects Composer package `muffin/trash` `^4`.

When absent, do not invent Laravel SoftDeletes / `deleted_at` global scopes as CakePHP defaults — use a documented project approach or install Trash.
