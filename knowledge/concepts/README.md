# concepts

Canonical “what is X” notes live primarily as **decisions** and **anti-patterns** today.

For 1.0, prefer these linked units over inventing parallel concept files:

| Concept | Where |
|---|---|
| Tables as persistence API | `decisions/orm-vs-connection-sql`, `rules/cakephp/tables` |
| Entity vs Active Record | `anti-patterns/active-record-entity` |
| Contain vs matching | `decisions/contain-vs-matching` |
| Validation vs rules | `decisions/validation-vs-application-rule` |
| Bulk vs entity save | `decisions/bulk-update-vs-entity-save` |

Future `concepts/*.md` units should only be added when a skill needs a shared definition that is not already a decision.
