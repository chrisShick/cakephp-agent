# CakePHP Authentication extension

Capability pack for **`cakephp/authentication` ^4.0** (CakePHP 5).

## Boundaries

- Teaches **who is the actor?** (identity) — not **may they do this?**
- Do **not** recommend Authorization policy APIs from this pack alone.
- When both AuthN and AuthZ are present, the integration pack `cakephp-authentication-authorization` adds joint guidance.

## Provenance

Verify against [Authentication docs](https://book.cakephp.org/authentication/3/en/index.html) / plugin source for the installed major (4.x for CakePHP 5).
