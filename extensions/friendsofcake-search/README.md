# FriendsOfCake Search extension

Capability pack for **`friendsofcake/search` ^7.0** (CakePHP 5).

## Boundaries

- Teaches Search filters, managers, Table finders, and PRG-oriented filtering.
- Does **not** assume FriendsOfCake CRUD unless that pack is also enabled.
- When both Search and CRUD are present, `integrations/friendsofcake-crud-search` adds joint guidance without duplicating base pack rules.

## Provenance

Verify against [FriendsOfCake/search](https://github.com/FriendsOfCake/search) docs for the installed major.
